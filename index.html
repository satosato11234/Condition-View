このサイトについて

このサイトは、データ処理、自動更新、Web可視化などの技術を学習するために開発された試作サイトです。

使用技術

  • フロントエンド: HTML5、CSS3、Vanilla JavaScript
  • データ処理: JSON形式のコンディション情報を取得・解析
  • 自動更新: GitHub Actionsによる定期データ更新
  • ホスティング: GitHub Pagesによる公開
